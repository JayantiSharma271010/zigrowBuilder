Frequently
asked questions

What is Website Builder?

Website Builder is an AI-powered platform that creates full-stack web applications from natural language descriptions.

What technologies are used?

We use Next.js, React, TypeScript, PostgreSQL, and Prisma ORM for a robust development experience.

How do I describe my app idea?

Simply write your app concept in plain English, and our AI will generate the application for you.

Can I customize the generated app?

Yes, you can make iterative changes and modifications through our live code editor.

What types of apps can I create?

You can create dashboards, e-commerce sites, blogs, CRMs, and more using our platform.

How is authentication handled?

We provide email/password, OAuth, and magic link login options for secure user authentication.
